# 🚀 AI Travel Agency – Setup Guide

## APIs Used

| Feature | API | Key Required | Cost |
|---|---|---|---|
| 🤖 AI Itinerary & Hotels | **Gemini AI** | ✅ Yes | Free tier available |
| 📍 City Geocoding | **Google Geocoding API** | Optional | Free (200 USD/month credit) |
| 📍 Geocoding fallback | **Nominatim (OpenStreetMap)** | ❌ No key | Completely free |
| 🗺️ Map + Place Search | **OpenStreetMap + Overpass API** | ❌ No key | Completely free |
| 🌤️ Weather | **Weatherstack** | ✅ Yes | Free tier available |
| 📰 Travel News | **Mediastack** | ✅ Yes | Free tier (500 req/month) |

> ✅ **Booking.com / RapidAPI has been removed.** Hotels are now generated by Gemini AI with direct links to Booking.com search.
> ✅ **Google Maps Places API removed.** Place discovery uses free OpenStreetMap + Overpass API — no key, no billing.

---

## Step 1 – Fill in API keys

Open `Backend/.env`:

```env
GEMINI_API_KEY=your_key_here          # https://aistudio.google.com/apikey
WEATHER_API_KEY=your_key_here         # https://weatherstack.com
GOOGLE_MAPS_API_KEY=your_key_here     # Optional — only for Geocoding API
MEDIASTACK_API_KEY=your_key_here      # https://mediastack.com (optional)
```

### Google Maps (Geocoding only — optional)
1. Go to https://console.cloud.google.com
2. Enable **Geocoding API** only (no Places API, no Directions API needed)
3. Create an API key

> **If you skip this**, the app automatically uses **Nominatim** (OpenStreetMap's free geocoder) as fallback. No setup needed.

---

## Step 2 – Run Backend

```bash
cd Backend
npm install
npm run dev
```

Server starts on **http://localhost:5000**

You'll see:
```
GEMINI_API_KEY =              ✅ Loaded
GOOGLE_MAPS_API_KEY (Geocoding) = ⚠️ Not configured (will use free Nominatim fallback)
```

## How the Places & Map tab works (no API key needed)

1. Frontend calls `POST /api/maps/geocode` → backend geocodes city → returns lat/lng
2. Frontend sends the lat/lng to **Overpass API** (free OpenStreetMap data) and fetches real places
3. An interactive **OpenStreetMap** embed shows the map with the location pinned
4. Click any place card → map recenters, Google Maps / website links appear

Categories: Attractions · Restaurants · Hotels · Shopping · Medical · Transport

## API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `POST /api/itinerary` | POST | Gemini AI structured day-by-day itinerary |
| `GET /api/hotels/:city` | GET | Gemini AI hotel suggestions |
| `GET /api/weather/:city` | GET | Live weather data |
| `POST /api/maps/geocode` | POST | City → lat/lng (Google Geocoding or Nominatim) |
| `GET /api/maps/reverse` | GET | lat/lng → address |
| `GET /api/news/:destination` | GET | Mediastack travel news |
| `GET /api/trains` | GET | Train routes |
